# Asset Sources & Licenses

Every asset in this repository is either **generated by the game's own code at runtime** or **bundled from a source whose license permits redistribution**, listed below. There is no runtime network access and no image-generation-service dependency.

## Generated at runtime (original)

| Asset | How |
|---|---|
| Terrain tiles (grass, stone, marsh, boards, temple floor…) | Seeded procedural painter (`src/render/painter.ts`, `src/render/textures.ts`) — value-noise brushes rendered into Phaser textures at boot |
| Walls, trees, cover, props (graves, tents, altars, bells, boats, shrines…) | Procedural painter (`src/render/props.ts`) |
| Character & monster standee tokens | Procedural frames + game-icons silhouettes (`src/render/textures.ts`) |
| Portraits | Procedural painted backgrounds + icon silhouettes (`src/ui/portraits.ts`) |
| Fog of war, lighting, overlays, zone effects | Runtime canvas generation |

These are deterministic (seeded) and require no source files.

## Iconography — CC BY 3.0

175 SVG icons from **game-icons.net**, bundled in `public/assets/icons/` with per-icon author attribution in `public/assets/icons/manifest.json` (authors include Lorc, Delapouite, Skoll, Caro Asercion, and others; full license text bundled as `LICENSE-CC-BY-3.0.txt`).

*Local modification:* the solid background rectangle each SVG ships with was removed so the icons work as CSS masks and canvas silhouettes. No other changes.
